> 一文带你了解 AI 搜索和 Web 智能体背后的技术原理和相关产品。

随着互联网技术的发展，信息搜索变得日益重要；高效地检索、评估、筛选和管理信息资源已成为必备技能。传统搜索引擎往往难以准确把握复杂的人类意图，因此获取最终答案常常耗时费力。近年来，大型语言模型（LLMs）在语言理解与生成方面表现突出，但在获取外部知识和最新信息上仍存在局限。**AI 搜索和 Web 智能体**通过将 LLMs 的能力融入传统互联网搜索流程，能够更好地应对复杂用户问题，显著提升信息浏览与检索的效率与准确性。

如下图所示，本文对近些年 AI 搜索相关的 80 余篇工作进行了深入回顾，重点涵盖：（1）基于文本的 AI 搜索、（2）Web 智能体、（3）多模态 AI 搜索与 Web 智能体、（4）基准评测、（5）AI 搜索软件与产品。更多细节可参考论文 *A Survey on AI Search with Large Language Models*。

## 1. 文本 AI 搜索

基于文本的 AI 搜索代表了信息检索系统的重大变革：它从传统搜索引擎发展到融合检索增强生成（RAG）工作流和深度搜索能力的复杂方法。其核心在于将 LLMs 强大的语言理解、生成能力与搜索引擎的海量信息获取能力相结合，以解决复杂的现实世界信息检索挑战。

一种高效且经典的 workflow 如下图所示，包含几个重要模块：**意图模型、问题改写模型、搜索引擎、网页重排模型、总结模型**。

*图 2. AI 搜索经典工作流图：User Question → Intent → Query Rewriter → Search API → Page Reranker → Summary。*

### 1.1 检索增强生成（RAG）工作流

朴素的 AI 搜索采用类似 RAG 的思路，本质上是**检索（Retrieval）**全网知识库来**增强（Augment）**大模型**生成（Generate）**准确答案的能力。

![基于 RAG 的 AI 搜索流程图](/images/ai-search-survey/image3.1.jpg)

*图 3. 基于 RAG 的 AI 搜索流程图：检索（Retrieval）—增强（Augment）—生成（Generate）。*

传统的 RAG 方法通过预定义的工作流程运行，主要包含四种范式：

1. **顺序 RAG**：采用线性的"检索—然后—生成"工作流，首先获取相关文档，然后基于这些文档生成最终回答。
2. **分支 RAG**：通过多个并行管道处理输入查询，每个管道都可能涉及自己的检索和生成步骤，然后合并输出以获得全面的答案。
3. **条件 RAG**：引入决策模块来自适应地确定给定查询是否需要检索，提高了系统的灵活性和鲁棒性。
4. **循环 RAG**：具有迭代、交互式的"检索—生成"循环，能够进行深度推理并处理复杂查询。

其中，条件与循环范式常以多轮工作流的形式呈现——模型先判断"是否需要检索"，再把检索结果与交互历史拼接后继续推理，如下图所示。

![多轮 / 循环 RAG 工作流](/images/ai-search-survey/image4.png)

*图 3b. 多轮 / 循环 RAG 工作流：模型自主判断 Need Search?，并将检索结果与交互历史迭代拼接。*

### 1.2 端到端深度搜索（Deep Search）

与传统 RAG 工作流不同，**深度搜索**方法通过在端到端连贯推理过程中调用搜索引擎来获取外部知识，以解决复杂的信息检索问题。其核心优势在于不需要预定义的工作流程：模型可以在推理过程中自主决定何时调用搜索相关工具，使其更加灵活有效。深度搜索让模型在遇到不确定信息时自主检索外部知识，有效解决了长链式思维推理中的知识空白问题，在数学、科学、编程和多跳问答任务中都表现出显著的性能提升。

![端到端深度搜索流程图](/images/ai-search-survey/image5.png)

*图 4. 端到端深度搜索流程图：推理模型在 Think ↔ Search ↔ Returned Info 之间交替，支持无需训练的指令增强，也可通过任务级优化（SFT / DPO / GRPO）进一步强化。*

**（1）无需训练的框架设计**

无需训练的方法通过精心设计的指令来增强推理模型的搜索能力，使模型能够意识到其任务性质以及如何正确使用搜索工具。**Search-o1** 等代表性工作提出了智能体 RAG 机制，允许推理模型在主要推理过程中遇到不确定信息时自主检索外部知识，并引入文档深度推理过程——在每次搜索调用后深度分析检索到的文档内容，将简洁有用的信息返回主推理链。后续的 **WebThinker、WebDancer、ManuSearch** 等工作进一步发展了这一范式，通常引入对收集网页 URL 的浏览功能，以实现深度网络探索。此外，WebThinker 等工作还探索了在收集信息的同时自主撰写研究报告，为用户提供更全面、前沿的知识。

**（2）基于后训练的方法**

基于训练的方法设计各种训练策略来激励或增强 LLM 在推理过程中的搜索能力，涵盖预训练、监督微调（SFT）和强化学习（RL）等多个层面：

- **预训练**：**MaskSearch** 框架引入检索增强掩码预测任务，训练模型使用搜索工具来填充被掩码的文本。
- **监督微调**：多种方法专注于合成包含搜索动作的长链式思维数据，如 **CoRAG** 通过拒绝采样自动生成检索链，**ReaRAG** 通过策略蒸馏构建专门的数据集。
- **强化学习**：近来获得了显著关注，包括基于 DPO 的方法以及基于 PPO、GRPO 等的训练策略。这些方法通过设计先进的奖励函数、结合结果与过程奖励、提升训练效率等方式，不断优化模型对搜索工具的使用效率与准确性。

## 2. Web 智能体

Agent 是一种自主的智能体，能够响应输入、执行上下文相关的动作，其核心目标是模拟人类的决策过程；而 **Web Agent** 是 Agent 在垂直领域的应用。不同于 AI 搜索，Web 智能体模拟人类浏览网页的过程，在当前网络环境上获取信息并决定后续操作。

### 2.1 基于提示词的 Web Agent

基于提示词的方法不需要调整模型参数，因而方便快捷、所需资源也较少。这类 Web Agent 致力于精心设计的提示词（Prompt）工程，将输入信息通过筛选、拼接、结构化等方式处理成特定格式的 Prompt，便于通用 LLM 理解并输出结果。例如 **WebVoyager** 将网页截图与网页结构化数据结合，形成 Prompt 输入 GPT-4V 进行处理，输出下一步操作，直至获取最终答案。

![基于提示词的 Web 智能体](/images/ai-search-survey/image6.png)

*图 5. 基于提示词的 Web 智能体：冻结参数的 LLM 结合动作空间（Action Space）与交互历史，在网络环境中循环决策。*

### 2.2 基于后训练的 Web Agent

鉴于 Web Agent 实际使用时网络环境与网页浏览任务的复杂性，往往需要通过 SFT 或 RL 等后训练来微调模型的网页知识，从而返回更可靠的下一步决策。**WebAgent-R1** 利用强化学习，以 DeepSeek-R1 为基础模型，通过改进的 GRPO 构建纯端到端 Web Agent；另一种常用方法是 SFT，如 **Falcon** 自主构建图形用户界面（GUI）数据集，再通过微调让 LLM 更好地处理 GUI 信息，增强 Web Agent 浏览 GUI 的能力。

## 3. 多模态 AI 搜索与 Web 智能体

### 3.1 多模态 AI 搜索

当用户的问题或答案中包含图片时，就需要多模态 AI 搜索；并且互联网上的信息往往以图文交织的形式呈现。例如：你在博物馆拍下一件古董的照片，想了解它背后的历史背景或相关人物，这就需要多模态 AI 搜索。近来，多模态大语言模型（MLLMs）在视觉感知、理解和推理中应用广泛，经典模型如 GPT-4V、LLaVA 等在学术界和工业界均有广泛应用。

![多模态 AI 搜索流程示例图](/images/ai-search-survey/image8.png)

*图 7. 多模态 AI 搜索流程示例：以文物图片 + 问题为输入，经 Search API 检索后由 MLLM（GPT-4o / Qwen-VL）给出答案。*

多模态 AI 搜索的代表工作包括 **MMSearch** 和 **MMSearch-R1**。MMSearch 将 AI 搜索流程中 requery、rerank、summarization 三个阶段里的 LLM 都替换成 MLLM；MMSearch-R1 则采用强化学习和多轮搜索的方式，进一步提升基于搜索的图片问答能力。

![两种多模态 AI 搜索方法](/images/ai-search-survey/image9.jpg)

*图 8. 两种多模态 AI 搜索方法：(a) MMSearch 的三轮流程（Requery → Rerank → Summarization），(b) MMSearch-R1 的多轮搜索。*

### 3.2 多模态 Web 智能体

这类 Web Agent 模拟人类视觉，通过辅助输入网页截图实现拟人化操作，显著提升在复杂网络环境中的任务完成效率。代表作有 **SeeAct、WebVoyager、WebWatcher**。例如这样的任务："在某汽车租赁网站上以最低价格租一辆轻型卡车"——多模态 Web 智能体利用类似 GPT-4V 的 MLLM 来视觉感知网页图片中不同类型的汽车，生成思维链，并输出可执行的网页操作。

## 4. 评测集

### 4.1 文本 AI 搜索评测集

**传统评测基准及其局限性。** 传统评测基准如 Natural Questions（NQ）、HotpotQA、FEVER 等，主要用于评估模型在多跳推理、事实核验等任务上的表现，数据源通常是维基百科等结构化知识库。然而随着大模型能力的飞速提升，这些传统评测集已逐渐"饱和"，顶尖模型接近满分，难以有效区分模型间的真实能力差距。

**现代浏览基准的挑战。** 为了更真实地反映现实世界的信息检索挑战，研究者们开发了新一代现代浏览基准，如 **BrowseComp、BrowseComp-ZH 和 Mind2Web 2**。这些评测集高度复杂且贴近真实应用场景，要求模型不再是简单地单次查询，而是像人类一样在复杂的互联网环境中进行持续的导航、推理和信息整合，解决需要多步骤才能找到答案的难题。

![AI 搜索评测集](/images/ai-search-survey/image10.jpg)

*图 9. AI 搜索评测集：(a) BrowseComp 与 (b) BrowseComp-ZH 中的高难度问题示例。*

以 BrowseComp-ZH 中的一个问题为例，要解决它，AI 模型必须具备以下能力：

1. **问题分解**：将一个复杂问题拆解为多个关于不同角色的独立信息线索。
2. **多轮搜索**：针对每个线索执行独立的网络搜索，如"1993 年出道的女演员""丈夫是湖州人的女演员"等。
3. **信息整合与推理**：将多轮搜索得到的分散信息进行交叉验证和关联，最终推理出所有线索共同指向的唯一答案。

这类高难度的评测任务，能够更精准地检验 AI 搜索模型在开放环境下的真实能力，从而推动技术向更智能、更实用的方向演进。

### 4.2 Web 智能体评测集

Web Agent 基准测试模拟现实世界网络环境中的交互式任务，评估智能体在导航、操作和推理方面的能力，主要分为两类：

- **通用评测基准**：评估 Web Agent 在多样网站完成任务的能力，如 **Mind2Web** 和 **WebArena**。
- **专用评测基准**：针对特定网站和任务，如 **DeepShop**（电子商务）和 **SafeArena**（恶意浏览安全）。

![Mind2Web 评测集](/images/ai-search-survey/image11.jpg)

**MMSearch** 评估了 MLLM 在 AI 搜索流程中三个任务上的能力；**LIVEVQA** 是图片知识问答，对于一些复杂或实时问题需要借助互联网搜索才能准确回答；**VisualWebArena** 则用于评估多模态 Web 智能体。

## 5. AI 搜索软件与产品

AI 搜索产品已迅速分化为**全球通用型产品、垂直领域产品和集成化助手**三大类别。

### 5.1 全球通用型 AI 搜索产品

作为深度研究的先驱，OpenAI 的 **ChatGPT DeepResearch** 和 **Perplexity DeepResearch** 使用最为广泛且效果优异，可以追踪热点话题，特别适用于学术调研、文献综述与技术写作。其他广泛使用的产品还有：Google 的 **Gemini DeepResearch**、字节 **豆包**、腾讯 **元宝** 等——豆包和元宝通过融入自家生态内容为用户提供更丰富的结果。此外还有 Nano AI、Kimi、DeepSeek、夸克、MiroMind ODR 和 Manus 等。

### 5.2 垂直领域 AI 搜索产品

- **MediSearch**：提供循证医学解答，如药物相互作用、治疗方案，大量医疗从业者将其用于临床决策支持。
- **Devv.ai**：代码专用搜索引擎，提供实时调试代码片段与 GitHub 集成，支持中文查询但仅限于编程场景。
- **Consensus**：覆盖 2 亿余篇科学论文，运用自然语言处理技术提取研究假设与方法论，在文献综述环节可节省约 50% 时间。

### 5.3 集成化 AI 搜索助手

- **WallesAI**：浏览器侧边栏助手，支持解析 PDF、视频及网页内容，实现跨文档问答与内容导出。
- **必应聊天（Bing Chat）**：深度集成 Edge 浏览器生态，通过实时网络索引与来源标注提供附带引文的答案，构建搜索—浏览一体化体验。

## 小结

从**经典 RAG 工作流**到**端到端深度搜索**，从**文本检索**到**多模态搜索与 Web 智能体**，AI 搜索正在把"检索—推理—浏览—生成"深度融合为一体。伴随 BrowseComp、Mind2Web 2、LIVEVQA 等高难度基准的出现，以及 DeepResearch 类产品的落地，这一方向正快速从学术研究走向真实应用。
